# CyberRecon-AI

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Kali Linux](https://img.shields.io/badge/Platform-Kali%20Linux-557C94)](https://www.kali.org/)
[![Termux](https://img.shields.io/badge/Platform-Android%20Termux-black)](https://termux.dev/)

CyberRecon-AI is a free, terminal-based, offline defensive reconnaissance suite for Kali Linux, Parrot OS, Android Termux, and Windows PowerShell. It implements the 150-point framework as 11 auditable domains, uses Python's standard library, and never sends scan data to an external AI service.

## Features

- WHOIS, DNS topology, TLS, mail-security, geo/infrastructure, ports, technology, headers, endpoints, sessions, and risk domains.
- Concurrent TCP probes, HTTP fingerprinting, sensitive endpoint checks, and deterministic offline risk correlation.
- Rich tables when installed, with a plain-text fallback when it is unavailable.
- JSON/Markdown audit exports, field-level scan diffs, and defensive UFW/Apache/Nginx remediation snippets.
- No API key, cloud service, external binary, or root privilege is required.

## Requirements

- Python 3.10 or newer.
- Kali/Debian with `apt-get`, Termux with `pkg`, or Windows with Python.
- Network access to the authorized target for live checks; analysis and reporting remain local.

## Installation

### Kali Linux

```bash
git clone https://github.com/your-account/CyberRecon-AI.git
cd CyberRecon-AI
chmod +x install.sh
./install.sh
```

### Android Termux

```bash
pkg update
pkg install git
git clone https://github.com/your-account/CyberRecon-AI.git
cd CyberRecon-AI
chmod +x install.sh
./install.sh
```

The installer detects `pkg` or `apt-get`, installs Python and Git, and installs the optional Rich dependency from `requirements.txt`.

### Windows PowerShell

```powershell
Set-ExecutionPolicy Unrestricted -Scope Process
.\install.ps1
.\.venv\Scripts\python.exe cyberrecon.py full example.com
```

The PowerShell installer locates Python (`py`, `python`, or `python3`), verifies Python 3.10+, creates `.venv`, and installs the requirements.

## Usage

```bash
python cyberrecon.py recon <target>
python cyberrecon.py mail <target>
python cyberrecon.py geo <target>
python cyberrecon.py ports <target>
python cyberrecon.py stack <target>
python cyberrecon.py headers <target>
python cyberrecon.py endpoints <target>
python cyberrecon.py session <target>
python cyberrecon.py score <target>
python cyberrecon.py full <target>
python cyberrecon.py diff <target>
python cyberrecon.py report <target> --format md
python cyberrecon.py wordlist --add /admin
python cyberrecon.py config-show
python cyberrecon.py --manual
python cyberrecon.py --version
```

`full` runs all 11 framework domains and writes `reports/<target>_full_audit.json`. `report` re-exports a JSON or Markdown audit. `diff` performs a field-level comparison against the stored audit baseline. Remediation files are written below `reports/remediation/` by the full audit.

## Framework domains

1. Domain intelligence (1-15)
2. DNS topology (16-30)
3. Email security (31-40)
4. Geo and infrastructure (41-50)
5. TLS chain (51-65)
6. Port scan (66-85)
7. Technology stack (86-100)
8. Headers (101-112)
9. Endpoints (113-132)
10. Session security (133-140)
11. Risk, controls, remediation, and reporting (141-150)

Run `python cyberrecon.py --manual` for the built-in reference.

## Security and privacy

The scanner makes only DNS, WHOIS, HTTP/HTTPS, TLS, and TCP checks against the target. No scan data leaves the local machine for analysis; reports are generated by deterministic local rules.
